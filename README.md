# Katina Biserova Metodieva – Interactive CV

A modern, interactive curriculum vitae with smooth animations and responsive design.

## 🌐 Live Demo

Your CV is now live at: **https://metodievakatina05-beep.github.io/Lebenslauf/**

## ✨ Features

- **Modern Design**: Dark gradient background with glassmorphism effects
- **Smooth Animations**: Fade-in effects and animated skill bars
- **Fully Responsive**: Works on all devices
- **Interactive Navigation**: Smooth scrolling between sections
- **Professional Layout**: Organized timeline, skills, and languages sections

## 📝 Sections

- **Profil**: Professional summary
- **Berufserfahrung**: Work experience timeline
- **Fähigkeiten**: Skills with visual progress bars
- **Sprachen**: Language proficiency levels
- **Kontakt**: Contact information

## 🛠️ Technologies

- HTML5
- CSS3 with animations
- Vanilla JavaScript
- Google Fonts (Inter)
